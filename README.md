# Lasur

Быстрый Android-браузер без рекламы в стиле Chrome. Чистая Java, без AndroidX, minSdk 26.

## Возможности
- Встроенный блокировщик рекламы и трекеров (EasyList, RuAdList, AdGuard Russian, StevenBlack hosts), пропуск видеорекламы YouTube
- Блокировка всплывающих окон и рекламных переходов
- Поиск и скачивание видео со страниц (включая HLS), просмотр во внешнем плеере
- Картинка в картинке, полноэкранный режим
- Вкладки и инкогнито, переключатель вкладок, панель вкладок на планшетах
- Менеджер паролей (шифрование ключом Android Keystore), автозаполнение
- Разрешения сайтов (микрофон, камера, местоположение)
- Темы (светлая, тёмная, AMOLED), 7 акцентных цветов, обои главной страницы
- 12 языков интерфейса: русский, English, Español, Português, Français, Deutsch, Türkçe, العربية, हिन्दी, 中文, 日本語, Bahasa Indonesia

## Сборка
Готовые APK собирает GitHub Actions (вкладка **Actions** → последний запуск → артефакт `Lasur-apk`).
При пуше тега `v*` (например `v1.8.0`) APK публикуется в **Releases**.

Локально нужны JDK 17, Android SDK (platform 36, build-tools 35) и Gradle 8.11+:

```bash
gradle testDebugUnitTest   # unit-тесты (AdBlocker, HLS)
gradle assembleRelease     # релиз собирается с R8 (minify + shrinkResources)
```

Иконки хранятся в `app/src/main/binres` в виде Base64 и распаковываются при сборке,
списки фильтров рекламы скачиваются автоматически (кешируются на 7 дней; сборка падает, только если
нет ни сети, ни ранее скачанной копии). `app/src/main/assets/psl.dat` — Public Suffix List
(https://publicsuffix.org) для определения регистрируемого домена.

### Подпись
Чтобы обновления ставились поверх установленной версии, APK нужно подписывать одним ключом.
Добавьте в **Settings → Secrets and variables → Actions**:

| Секрет | Значение |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | keystore в Base64 |
| `SIGNING_STORE_PASSWORD` | пароль keystore |
| `SIGNING_KEY_ALIAS` | alias ключа |
| `SIGNING_KEY_PASSWORD` | пароль ключа |

Без секретов APK подписывается отладочным ключом.

## 1.9.0

- Новая иконка: лазурная капля с буквой L на тёмно-синем фоне (векторная адаптивная иконка, чёткая на любом экране и в любой маске лаунчера). Тот же логотип — на вкладках и домашней странице.
- Новая анимация запуска: капля падает сверху, «шлёпается» с упругим сжатием, от неё расходятся круги, затем появляется надпись Lasur. На Android 12+ системная заставка теперь без значка, чтобы анимация шла сразу и без двойного логотипа.

## 1.8.9

- Возврат из PiP всегда открывает обычную страницу, без полноэкранного режима (в том числе если PiP был запущен из полноэкранного видео).
- После PiP со страницы снимаются все служебные стили PiP и полноэкранного плеера, а YouTube получает событие изменения размера окна и заново раскладывает сетку — главная страница больше не остаётся без отступов и с пустой полосой справа.

## 1.8.8

- После возврата из PiP плеер YouTube больше не показывает «паузу» (кнопку Play и застывшие контролы), когда видео на самом деле играет: состояние плеера синхронизируется с реальным воспроизведением.
- Восстановленный после PiP полноэкранный режим больше не показывает чёрный экран с шапкой YouTube поверх: шапка сайта скрывается, плеер и видео растягиваются на весь экран, кнопка выхода не перекрывает элементы страницы.

## 1.8.7

- PiP YouTube: если плеер успел встать на паузу за мгновение до ухода на рабочий стол (или параметры авто-входа устарели), Android 12+ теперь входит в PiP вручную, а не остаётся без окна.
- При авто-входе (Android 12+) страница готовится к PiP сразу при уходе: в уменьшающемся окне видно только видео, без панелей браузера.
- Учитывается недавнее воспроизведение (до 2 с), чтобы пауза YouTube при сворачивании не отменяла PiP.
- Отслеживание видео больше не пересчитывает раскладку на каждом событии прокрутки: меньше подтормаживаний при скролле на тяжёлых страницах.

## 1.8.6
- Возврат из PiP сохраняет прежний полноэкранный режим и ориентацию. Если WebView закрыл HTML fullscreen при сворачивании, браузер возвращает выбранный плеер в собственный полноэкранный контейнер с кнопкой выхода.
- Блокировка фоновой паузы отключается при возвращении в приложение. Ручные нажатия и касания плеера учитываются; кнопка паузы PiP вызывает сохранённый метод остановки видео, обходя переопределения сайта.
- Состояние кнопки PiP обновляется по фактическому воспроизведению, без предварительного переключения иконки. Возврат в полноэкранный режим сохраняет паузу и текущую позицию.

Проверки: `node scripts/test-pip.mjs` (26 сценариев), Android unit-тесты и сборка в CI.
На устройстве: полноэкранный YouTube → PiP → пауза → раскрытие (полноэкранный и на паузе) → воспроизведение/пауза кнопкой сайта → выход из fullscreen; повторить с портретным видео и несколько раз подряд.

## 1.8.5
- Удалена кнопка оформления со смещением за верхний край главной страницы. Темы и обои доступны через меню и настройки.
- WebView сохраняет видимость поверхности только при входе в PiP и внутри PiP, чтобы сигнал скрытого окна не останавливал видео. При раскрытии и закрытии восстанавливается обычная обработка видимости.
- Программная пауза YouTube для выбранного ролика блокируется во время PiP, включая повторную паузу после нажатия «Воспроизвести». Ручная пауза в PiP и системных медиакнопках, закрытие окна, смена страницы и выключение функции остаются рабочими.

Проверки: `node scripts/test-pip.mjs` (20 сценариев), Android unit-тесты и сборка в CI.
На устройстве: YouTube → PiP → воспроизведение минимум 2 минуты → несколько циклов пауза/воспроизведение → раскрытие/закрытие; главная страница без невидимой кнопки.

## 1.8.4
- PiP исключает предпросмотры YouTube в ленте и рекомендациях; поддерживает обычный плеер, Shorts и embed.
- Защита от фоновой паузы устанавливается до скриптов сайта, сохраняется при длительном воспроизведении и учитывает повторную паузу при изменении размера окна. Автовосстановление ограничено переходом в PiP; пользовательская пауза сохраняется.
- После раскрытия PiP восстанавливаются состояние адресной строки, поиск по странице и панель вкладок. В PiP скрыты загрузка видео, подсказки и уведомления.
- Плавающая кнопка и уже открытые сообщения следуют за нижней панелью во время её анимации.

Проверки: `node scripts/test-pip.mjs` (15 сценариев), `gradle testDebugUnitTest`, `gradle assembleRelease`.
На устройстве: YouTube после 30 секунд воспроизведения → Home → PiP; пауза/воспроизведение, раскрытие/закрытие; YouTube Home/подписки с предпросмотром → Home без PiP; обычное видео и Shorts; верхняя/нижняя панель, поиск по странице и планшетная панель вкладок до и после PiP.

## 1.8.3
- Исправлены first-party правила и условные исключения блокировщика.
- Разрешения инкогнито хранятся только в текущей вкладке; неподдерживаемый приватный профиль блокирует загрузку сайтов.
- Blob-загрузки требуют подтверждения, привязаны к вкладке и документу, ограничены по размеру и очищаются при ошибках.

- Исправлены отмена анимаций панели и реакции на scroll-события от изменения разметки; увеличены основные зоны нажатия, улучшен контраст оранжевой темы.

Проверки: `gradle testDebugUnitTest`, `node scripts/test-pip.mjs`, `gradle assembleRelease`.
На устройстве: проверить Home → PiP → пауза/воспроизведение → раскрытие/закрытие, полноэкранное и вертикальное видео, выход «Назад» без PiP. Проверить прокрутку вниз/вверх и смену вкладки во время скрытия верхней и нижней панели.
