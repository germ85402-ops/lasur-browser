# Lasur

Быстрый Android-браузер без рекламы в стиле Chrome. Чистая Java, без AndroidX, minSdk 26.

## Возможности
- Встроенный блокировщик рекламы и трекеров (EasyList, RuAdList, AdGuard Russian, StevenBlack hosts), пропуск видеорекламы YouTube
- Блокировка всплывающих окон и рекламных переходов
- Поиск и скачивание видео со страниц (включая HLS), просмотр во внешнем плеере
- Картинка в картинке, полноэкранный режим
- Вкладки и инкогнито, переключатель вкладок, панель вкладок на планшетах
- Менеджер паролей (шифрование ключом Android Keystore), автозаполнение
- Разрешения сайтов (микрофон, камера, местоположение)
- Темы (светлая, тёмная, AMOLED), 7 акцентных цветов, обои главной страницы
- 12 языков интерфейса: русский, English, Español, Português, Français, Deutsch, Türkçe, العربية, हिन्दी, 中文, 日本語, Bahasa Indonesia

## Сборка
Готовые APK собирает GitHub Actions (вкладка **Actions** → последний запуск → артефакт `Lasur-apk`).
При пуше тега `v*` (например `v1.8.0`) APK публикуется в **Releases**.

Локально нужны JDK 17, Android SDK (platform 36, build-tools 35) и Gradle 8.11+:

```bash
gradle testDebugUnitTest   # unit-тесты (AdBlocker, HLS)
gradle assembleRelease     # релиз собирается с R8 (minify + shrinkResources)
```

Иконки хранятся в `app/src/main/binres` в виде Base64 и распаковываются при сборке,
списки фильтров рекламы скачиваются автоматически (кешируются на 7 дней; сборка падает, только если
нет ни сети, ни ранее скачанной копии). `app/src/main/assets/psl.dat` — Public Suffix List
(https://publicsuffix.org) для определения регистрируемого домена.

### Подпись
Чтобы обновления ставились поверх установленной версии, APK нужно подписывать одним ключом.
Добавьте в **Settings → Secrets and variables → Actions**:

| Секрет | Значение |
|---|---|
| `SIGNING_KEYSTORE_BASE64` | keystore в Base64 |
| `SIGNING_STORE_PASSWORD` | пароль keystore |
| `SIGNING_KEY_ALIAS` | alias ключа |
| `SIGNING_KEY_PASSWORD` | пароль ключа |

Без секретов APK подписывается отладочным ключом.

## 1.8.3
- Исправлены first-party правила и условные исключения блокировщика.
- Разрешения инкогнито хранятся только в текущей вкладке; неподдерживаемый приватный профиль блокирует загрузку сайтов.
- Blob-загрузки требуют подтверждения, привязаны к вкладке и документу, ограничены по размеру и очищаются при ошибках.
- PiP сохраняет пользовательскую паузу, управляет выбранным видео и останавливает воспроизведение после закрытия окна. На Android 12+ используется системный авто-вход.
- Исправлены отмена анимаций панели и реакции на scroll-события от изменения разметки; увеличены основные зоны нажатия, улучшен контраст оранжевой темы.

Проверки: `gradle testDebugUnitTest`, `node scripts/test-pip.mjs`, `gradle assembleRelease`.
На устройстве: проверить Home → PiP → пауза/воспроизведение → раскрытие/закрытие, полноэкранное и вертикальное видео, выход «Назад» без PiP. Проверить прокрутку вниз/вверх и смену вкладки во время скрытия верхней и нижней панели.
